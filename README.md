# common_libs

A modular collection of commercial-safe C++ libraries with Lakos-style layering and minimal dependencies.

## Goals
- High performance, modularity, and clear dependency boundaries.
- Few, larger libraries with cohesive responsibilities.
- Each component has a `.h/.cpp` pair and is documented.
- Tests and examples for every library.
- Commercial-safe licensing (no LGPL/GPL code copied).

## Libraries
- ds_base
- ds_core
- ds_memory
- ds_math
- ds_data
- ds_system
- ds_io
- ds_net
- ds_gui_bridge
- ds_app

See `doc/DS_LIBS.md` for architecture, dependencies, and usage.
