# ds_core

## Overview
Core utilities built on `ds_base` for common application needs.

## Responsibilities
- String and text utilities.
- Time and date helpers.
- Filesystem abstraction and logging.
- Configuration primitives (no heavy parsing).

## Dependencies
- `ds_base`
