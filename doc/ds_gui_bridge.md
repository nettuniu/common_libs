# ds_gui_bridge

## Overview
GUI-agnostic interfaces and adapters for connecting core and GUI.

## Responsibilities
- Interfaces for event, state, and command flow.
- Data transport helpers (including QByteArray-like buffer utilities).
- Bridges to specific GUI frameworks through adapters.

## Dependencies
- `ds_base`
- `ds_core`
