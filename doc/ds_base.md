# ds_base

## Overview
Lowest layer with small, stable utilities used everywhere.

## Responsibilities
- Basic macros, assertions, and error codes.
- Lightweight helpers that do not allocate.
- Simple, stable types used across higher layers.

## Dependencies
- None.

## Public Headers
- `ds_base/ds_base.h`: core shared utilities and version info.
